# AutoSDK：连接手机，开始调试

1. 手机打开 AutoSDK，开启 **Wi-Fi 调试**，允许“本地网络”权限。手机和电脑连接同一个可信 Wi-Fi。
2. 点击 VS Code 左侧 **AutoSDK 手机图标**，打开“设备与调试”。
3. 点击 **搜索 Wi-Fi 手机**，在手机卡片上点 **添加并连接**。
4. 首次输入手机显示的 **配对码（Debug Token）**。这不是代码；正常流程不需要输入 IP、端口、命令或编辑设置文件。
5. 显示“已连接”后，点 **新建示例脚本 → 运行整个脚本**。脚本可以不保存就运行。
6. 点 **截图与节点**，查看手机画面、点选控件，生成并插入操作代码。

再次打开 VS Code，在侧栏点“连接”；手机 IP 变化后重新搜索并选择同一手机，会复用当前工作区的配对信息。切换到另一台手机或不同工作区需要重新配对。重装 App 或更换手机配对码后，点“重新配对”。

## 常用按钮

- **运行整个脚本**：执行侧栏显示的脚本文件，不要求保存；也可点编辑器右上角 ▶ 或右键运行。
- **只运行选中代码**：只执行当前单个非空选区。每次都是新上下文，不保留上次的变量。
- **停止脚本**：发送停止请求。纯 JavaScript 无限循环目前不能保证强制中断。
- **运行日志**：查看执行结果和详细错误。
- **断开**：关闭电脑与手机的连接，不删除配对信息。

## 搜索不到或连接失败

保持手机 App 前台运行；检查 Wi-Fi 调试开关、本地网络权限，以及是否连接了访客网络。公共网络、AP 隔离或防火墙可能阻止广播。

先点“重新搜索”，配对失败点“重新配对”。只有广播被屏蔽时才展开“更多连接方式”，手动填写手机地址。USB 是高级备用方式，需要额外的电脑端驱动和工具。

配对码保存在 VS Code 的安全存储中，不出现在侧栏、广播或设置 JSON。请只连接可信局域网；广播身份不等于经过密码学验证的设备身份。

未信任的工作区不能运行或部署脚本；请通过 VS Code 的工作区信任提示确认。当前提供运行、停止、日志、截图和节点采集，**不提供断点单步调试**。跨 App 操作仍取决于宿主权限、签名与 iOS 运行时能力。
