# 与 AScript 的工作流对比

核对日期：2026-09-07。以下只比较官方可核实的产品流程，不把宣传性能当作实测结果。

AScript 当前官方 [iOS 介绍](https://www.ascript.cn/docs/ios/intro/) 描述了
Python Agent/no-WDA 引擎；[AI Studio 文档](https://www.ascript.cn/docs/ai/studio/)
描述了配对后的屏幕、节点、工程同步、日志与运行/停止闭环。
本文删除了旧版“当前 AScript 必须 WDA 激活”的描述。

| 使用环节 | AScript 官方流程 | AutoSDK v1.38.0 |
| --- | --- | --- |
| 编写 | Python 语言服务与云端工程 | 本地 VS Code 的 JS/TS 补全、示例；单文件转译 |
| 接入 | 手机配对到工作区 | 同局域网 Bonjour 扫描、选择添加、token 配对；手填 IP 兜底 |
| 验证 | 真机屏幕/节点、图色/OCR、日志、运行/停止 | 关联截图与节点 Inspector、代码生成、日志、全文件或选区运行、协作式停止 |
| 工程交付 | 云端工程管理与增量同步 | 单脚本/图片部署、CI IPA/VSIX；尚无工程打包器 |
| 安全边界 | 官方说明设备与账号/工程/会话绑定 | 工作区/设备 token 隔离、可信工作区限制、沙盒、受控网络 |
| 运行范围 | 按 AScript 的设备/版本/模式要求 | UIKit 仅宿主；内置私有适配器依赖签名/系统/真机能力报告 |

本轮优化：选区独立运行、迟到结果不覆盖当前选择、扫描资源清理、定位/VPN 可取消等待、
错误保留 underlying、过时安装说明清理。没有添加未经实现的云控、视频流、断点调试或
任意系统开关来制造“能力数量相同”的印象。

下一步先完成真实 iPhone 的首次连接/重连/后台挂起与跨 App 能力验收，
再推进设备列表切换、工程级资源同步和可观测调试；详见 [整体审计](QUALITY_AUDIT.md)。
