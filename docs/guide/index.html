1这是什么

AutoSDK 是一套可复用的 iOS 自动化脚本框架，包含三部分：

  • 模板 App（AutoSDKTemplate）：装到 iPhone 上的脚本宿主，内置脚本列表、编辑器、导入/导出、设置页。
  • VS Code 插件（AutoSDK Script Tools）：在电脑上写脚本、连手机调试、可视化检查 UI、远程构建 IPA。
  • AutoSDK 引擎：Objective-C 写的脚本执行引擎（SPM / CocoaPods 可集成进你自己的 App）。

典型工作流：电脑写脚本 → 一键发送/运行到手机 → 手机执行并回报日志 → 调试 UI/截图 → 构建新 IPA 安装。

脚本风格与 AutoScript / Auto.js 高度一致：auto.click、device、file、storages、toast 等都能直接用。

3安装

3.1 环境要求

  • 一台 iPhone（推荐 iOS 14+，已装 TrollStore 用于装未签名 IPA）
  • Windows 或 macOS 电脑
  • VS Code 1.85+、Node.js 22+（写脚本 + 插件需要）
  • USB 线（推荐 USB 隧道方式），或同一可信 Wi-Fi 网络（直连方式）

3.2 安装 App（TrollStore）

  1. 把 AutoSDKTemplate.ipa 传到 iPhone（隔空投送 / 微信文件 / iCloud 云盘均可）。
  2. 在 iPhone 的“文件”App 里找到 IPA → 长按 → 共享 → 用“TrollStore”打开 → 安装。
  3. 打开 AutoSDK Template：主界面是脚本列表（内置 hello.js、demo-api.js）。
IPA 未签名（CODE_SIGNING_ALLOWED=NO），普通方式装不上；只能用 TrollStore 或你自己的开发者证书签名后安装。

3.3 安装 VS Code 插件

code --install-extension "E:\ios脚本框架开发\vscode-extension\autosdk-vscode-0.4.0.vsix" --force

安装后命令面板（Ctrl+Shift+P）输入 AutoSDK 能看到全部命令。

3.4 安装 iproxy（USB 隧道可选，Wi-Fi 直连可跳过）

Windows 安装 libimobiledevice 发行版，确保 iproxy 在 PATH；或在插件设置里指定 autosdk.iproxyPath。验证：

iproxy --version

4连接 iPhone

4.1 拿到调试地址和 Token

手机打开 AutoSDK Template → 点左上角齿轮进入设置：会显示 Debug URL（如 ws://192.168.1.8:9001 或 ws://127.0.0.1:9001）和 Debug Token。Token 每次安装随机生成，只显示在 App 里，别外传。

4.2 方式 A：USB 隧道（推荐，稳定）

  1. iPhone 用 USB 线连电脑，解锁并保持 App 在前台。
  2. VS Code 命令面板执行 AutoSDK: Start USB Tunnel（自动跑 iproxy 9001:9001）。
  3. 手动方式：iproxy 9001:9001 保持窗口开着。
  4. 连接 URL 填 ws://127.0.0.1:9001。

4.3 方式 B：Wi-Fi 直连（无需数据线）

  1. 电脑和手机连同一个 Wi-Fi，App 首次会弹“本地网络”权限，点允许（设置里 Allow Wi-Fi connections 保持开）。
  2. 设置页复制 ws://手机IP:9001 的地址。
  3. 注意：公司/访客 Wi-Fi 的“AP 隔离”会阻止直连，连不上就换 USB。

4.4 在 VS Code 里配置连接

  1. 命令面板 → AutoSDK: Configure Device Connection。
  2. 填入上面的 ws://... URL 和 Token（Token 存 VS Code SecretStorage，不落盘明文）。
  3. 命令面板 → AutoSDK: Test Device Connection，看到成功即连上。

也可以不用 VS Code，用命令行调试客户端：

cd E:\ios脚本框架开发
node tools/debug-client.mjs --token <你的token> --url ws://127.0.0.1:9001 --script "toast('hello'); 1+1;"

5第一行代码

5.1 新建脚本文件

在 VS Code 里打开任意文件夹，新建 hello.js，写：

// 第一行代码：读取设备信息并弹提示
const info = device.getDeviceInfo();
console.log("device:", info.model, info.systemVersion);
toast("hello from AutoSDK");
auto.sleep(500);
// 宿主 App 内自动化（AutoUIKitAdapter 只控制本 App 的界面）
auto.click({ label: "AutoSDK Scripts", type: "Button" });
// 结果值会显示在日志面板
({ model: info.model, ok: true });

5.2 运行

  1. 确认已连接（第 4 节），手机 App 保持前台解锁。
  2. 命令面板 → AutoSDK: Run Current Script。
  3. VS Code 通知/输出面板显示运行结果与 console.log 日志；手机 App 的日志区同步显示。

5.3 存到手机 / 管理手机脚本

  • AutoSDK: Send Current Script to Device：把当前文件转译成 .js 存进手机沙盒（debug-scripts/），不运行。
  • AutoSDK: Manage Device Scripts：列出/运行/删除手机上的脚本。
  • 手机 App 的脚本列表里也会出现刚发送的脚本，点 ▶ 直接运行。

6调试

命令用途
AutoSDK: Run Current Script直接运行当前编辑器内容，不用重新构建 IPA
AutoSDK: Stop Active Script停止正在运行的脚本（配合超时、定时器协作用）
AutoSDK: Capture Device Screenshot截图并保存到电脑
AutoSDK: Inspect Device Nodes抓取界面节点树，定位可点击控件
AutoSDK: Open Visual Inspector可视化：截图 + 节点树 + 选择器/找图/OCR 测试，自动生成点击代码
AutoSDK: Build TrollStore IPA远程触发 GitHub Actions 构建，自动下载新 IPA（无需 Mac）

6.1 可视化检查 UI（最重要）

  1. 命令面板 → AutoSDK: Open Visual Inspector。
  2. 左侧截图，右侧节点树：点节点会高亮并生成选择器代码。
  3. “测试选择器”立即执行；找图/OCR 模式可先用本地 PNG 测试（自动上传到手机 debug-assets）。
  4. 生成的 auto.click 代码直接粘回脚本。

6.2 跨 App 自动化（WDA）

默认 AutoUIKitAdapter 只能控制 App 自己的界面。要控制其他 App：

  1. 手机上有 WDA 兼容 Runner（如 WebDriverAgent，需单独签名运行）。
  2. App 设置页打开 Use WDA adapter，填 Runner URL（默认 http://127.0.0.1:8100）和目标 App 的 Bundle ID → Apply。
  3. 之后 auto.click / app.homeScreen() / app.lock() / device.volumeUp() / device.volumeDown() / device.isScreenOn() 等走 WDA 执行。
TrollStore 环境不保证每个 iOS 版本都能跑起 WDA Runner；跨 App 自动化能力取决于你的 Runner。

6.3 命令行快速试脚本

node tools/debug-client.mjs --token <token> --url ws://127.0.0.1:9001 --script-file .\hello.js

7手机端 App 直接用

不接电脑也能用：

  • 运行：列表选中脚本 → 右上 ▶；停止用 ■。
  • 新建/编辑：工具栏 + 打开编辑器，写完后点保存（自动校验名字与大小，最大 768 KB）。
  • 导入：工具栏文件夹按钮从 Files 选 .js/.txt/.mjs；或电脑上把文件放进“文件”App → 长按 → 共享 → 用 AutoSDK Template 打开。
  • 导出：工具栏分享按钮把脚本导出到 Files/隔空投送。
  • 重命名/删除：选中后工具栏文本图标重命名；左滑删除。

8常见问题

连不上 / Test Connection 失败

  • 手机 App 保持前台解锁（TrollStore 装的普通 App 后台会被 iOS 挂起，WebSocket 会断）。
  • USB 方式：确认 iproxy 在跑、URL 是 ws://127.0.0.1:9001、端口没被占用。
  • Wi-Fi 方式：确认同一网段、App 本地网络权限已允许、路由器没有 AP 隔离。
  • Token 填错会直接拒绝：重跑 Configure Device Connection。

脚本卡死 / 死循环

纯 JS 死循环（如 while(true){}）JavaScriptCore 无法硬中断，可能占满 CPU：用 Stop Active Script 配合桥接调用与定时器可中断；极端情况重启 App。别在脚本里写无出口死循环。

点不到别的 App 的按钮

默认适配器只能操作宿主 App 自己。跨 App 需要 WDA Runner（见 6.2）。

怎么把图片/视频/截图存进系统相册

用 media.saveImage('images/a.png')、media.saveVideo('videos/a.mp4')、media.saveScreenshot() 或 media.saveImageBase64(auto.screenshot())。第一次调用会弹 iOS 相册授权，App 已内置 NSPhotoLibraryAddUsageDescription；拒绝后脚本会报错而不是假装成功。

IPA 怎么来的 / 怎么换 Bundle ID 上架

CI（GitHub Actions）自动构建未签名 IPA；要上架/换包名，改 Examples/TemplateApp/project.yml 的 PRODUCT_BUNDLE_IDENTIFIER 和 App/Info.plist 的显示名/图标，发布清单见 docs/MARKET_RELEASE.md。App Store 对脚本执行与调试服务器审查风险高，主流分发走 TrollStore/侧载。
